runs/ berisi artefak cron otonom. Ditulis .github/workflows/daily.yml,
bukan tangan manusia. Lihat TASK_MELCO.md M4.

Bentuknya:
  runs/YYYY-MM-DD/run.log         log sapuan Tier-1, ber-timestamp
  runs/YYYY-MM-DD/watchlist.json  kandidat untuk agen + sinyal + biaya kredit
  runs/investigations/            transkrip agen (tahap 2, mulai ~19 Sep)
  runs/backfill/                  himpunan positif berlabel untuk kalibrasi Hamzah
